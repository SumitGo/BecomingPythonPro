13. Various Datatypes in python:
    Int
    - a datatype to store integer values, from - inf to + inf.
    - default value is 0
    - a single value datatype

    Float
    - float datatype is used to store deciaml values.
    - default value is 0.0

    Bool
    - This datatype is used when we need answers in True or False, 0 or 1.
    - we can convert various datatype of variables into bool, the result will be in True or False
    - For e.g. bool(4.5) -> True
    - Empty or default values typically converts to False.

    Str
    - a datatype used to store strings or collection of characters,
    - it is immutable datatype, that means data once created cannot be manipulated
    - it can store characters like A-Z, a-z, special characters, numbers

18. List and tuple are both collections of objects.
    Difference b/w list and tuple:
    - List is mutable, it allows changing its content.
    - tuple doesnt allow changing its content, its immutable.

    -List is made with square brackets -[]
    -Tuple is made with paranthesis -()

    -List is not used where security is related.
    -Tuple is used when security is needed.

19. Difference b/w set and dictionary:-
    - Set is mutable datatype object, it allows changing its content.
    - Dictionary is also mutable and allows changing its content.

    - Set contains unique elements in unorganized manner, so no indexing can be performed, no order of elements exist.
    - Dictionary contains data in the form of key and vlaue pairs. Keys should be immutable objects, values are mutable.

    - Set only allows immutable objects to be entered.
    - Dictionary can store any kind of data according to the key value pairs rules.

    These operators perform logical comparision on two values:
